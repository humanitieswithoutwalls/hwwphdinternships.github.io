# Sustainability

## Advocating for Future Program Iterations 

* Identify units on campus who would be interested in collaboration and/or cost sharing
* Identify funding streams
* If seeking internal institutional funding, who at the administration level do you need start conversations with or send letters of inquiry to?

### Putting Together a Program Overview Document to Share with Administrators and Funders
This document should concisely tell the reader the following:
* What the program did
* Who was involved
* Why it matters
* What is needed to do it again
* What value it brings to the broader campus community

## Documentation

Conducting assessment at the end of each program iteration is an effective way to help the next year run smoothly. Document who was involved (students, organizations, staff) and the roles they each played. The following questions to identify and document strengths and/or changes you want to make.
* What went well?
* Did your planning and program timeline work well? Do any adjustments need to be made?
* What challenges did you encounter? How can you plan for them in future years?
* What would you do differently in future versions?
